# Tell Me About Palestine - احكيلي عن فلسطين

An educational mobile application for children aged 6-12 that presents Palestinian facts, statistics, geography, culture, heritage, and daily life in a positive, engaging, and interactive way.

## Overview

This app aims to educate children about Palestine through:
- Interactive stories and narratives
- Fun games and challenges
- Animated mascots and characters
- Bilingual support (Arabic & English)
- Beautiful visualizations and maps
- Educational mini-games
- Progress tracking and achievements

## Key Features

### 🌍 Explore Palestine
- Interactive map of Palestinian cities and landmarks
- Beautiful photos and 360° views
- Fun facts about each location
- Audio guides in Arabic and English

### 📖 Stories
- Age-appropriate stories about Palestinian culture, history, and daily life
- Audio narration available
- Beautiful illustrations
- Interactive story elements

### 🎮 Games
- Memory matching games
- Jigsaw puzzles
- Educational quizzes
- Coloring books
- Word search games

### 🎵 Music & Sounds
- Traditional Palestinian music
- Educational songs
- Instrument explorer

### 🏆 Progress Tracking
- Badges and achievements
- Level system
- Daily challenges
- Parent/teacher dashboard

## Tech Stack

- **Framework**: React Native with Expo
- **Language**: TypeScript
- **Navigation**: React Navigation 6
- **State Management**: Zustand
- **Animations**: React Native Reanimated, Lottie
- **Internationalization**: i18next
- **Offline Storage**: AsyncStorage, WatermelonDB (planned)

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn
- Expo CLI
- iOS Simulator or Android Emulator (for development)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/Tell-Me-About-Palestine.git
cd Tell-Me-About-Palestine
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Run on iOS or Android:
```bash
npm run ios
# or
npm run android
```

## Development Scripts

- `npm start` - Start Expo development server
- `npm run android` - Run on Android emulator
- `npm run ios` - Run on iOS simulator
- `npm run web` - Run in web browser
- `npm test` - Run tests
- `npm run lint` - Lint code
- `npm run format` - Format code with Prettier

## Design Principles

### Child-Friendly Design
- Large, tappable buttons
- Rounded shapes and friendly colors
- Minimal text, maximum visuals
- Playful animations

### Color Palette
- **Olive Green** (#66BB6A) - Growth, land, heritage
- **Sky Blue** (#2196F3) - Hope, future
- **Warm Beige** (#FFC107) - Cultural warmth
- **Soft Red** (#F44336) - Energy, passion

### Mascots
- **Zaytoun** (زيتون) - The wise olive tree
- **Noor** (نور) - The curious child explorer
- **Huda** (هدى) - The guiding bird
